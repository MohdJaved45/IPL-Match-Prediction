# 🏏 IPL Match Prediction & Dashboard App

A Streamlit-based web application designed to analyze IPL match statistics, view team & player performance, and predict IPL match outcomes using Machine Learning.

---

## ✨ Features

* **Match Prediction**: Predict match winners based on historical performance and team selections.
* **Interactive Dashboard**: Explore IPL stats, champions list, and head-to-head records.
* **Player Stats & Gallery**: Detailed insights into player performances and visual highlights.
* **Custom UI & Styling**: Enhanced interface with customized CSS and visual themes.

---

## 🛠️ Tech Stack

* **Frontend / Web Framework**: [Streamlit](https://streamlit.io/)
* **Machine Learning**: Scikit-learn, Pandas, NumPy
* **Language**: Python 3.x
* **Styling**: Custom CSS (`style.css`)
